# 枫林城

> *"枫林城其实也不算小，对于很多世代居此的人来说，甚至这就是世界全部。"*
> —— 原著第 3 章

## 核心简介

**枫林城**是庄国清河郡下辖的城池之一。以规模而论，在本郡十三城中居于尾列，仅在茂城之前。城中以代表庄国意志的**城主府**为尊，而**张、方、王三大姓**则是这方地界事实上的主人。因庄国以道门为国教，遍布全国三郡各城的道院象征国家超凡力量，故**枫林城道院**才是全城最贵要之地——其地位甚至在城主府与三大姓宅门之上。

城郊的还真观外，曾发生秦、楚两国强者借庄国国境悍然交战的重大事件，此事成为庄国之耻，也是城内局势暗流涌动的背景之一。

## 地理与格局

整座枫林城**四四方方，规划齐整**：

| 区域 | 功能 |
| --- | --- |
| **城中心** | 城主府，辐射四方 |
| **东城** | 枫林道院的地盘 |
| **城西** | 豪门贵室宅邸（如方府） |
| **南城** | 多为平民聚居 |
| **城北** | 商人富贾聚集 |

### 周边地物

- **还真观**：位于枫林城郊野的一座残破道观，年久失修、匾额字迹模糊，仅"还真"二字隐约可辨。观外曾爆发强大修者之战（李一于此一剑枭首左光烈），战后余波引动枫林城方面查探。
- **西山**：城郊贼匪"西山贼匪"盘踞之地，曾袭杀姜望；后被枫林五侠联手剿杀。
- **绿柳河**：清河的支流，绕牛头山而过，河水清澈。枫林五侠当年即在此河畔结义。
- **望月楼**：城中酒楼，方鹏举借方得财之手诱姜望至此饮下毒酒之处。
- **倚翠楼**：城中销金窟，方家仆从方得财常出入之地。

## 城内势力

### 城主府

- 城主**魏去疾**，声音洪亮可传遍全城，乃**大将军皇甫端明的旧部**。
- 在左道妖人夜袭道院事件后，魏去疾公开回应董阿："此事本府定有交代！无论涉及何人、何事，一旦揪出，定杀不饶！"
- 众所周知，**魏去疾与道院院长董阿并不相合**——二人分属朝中不同派系，构成城内最微妙的政治格局。

### 张、方、王三姓

三大姓是除城主外这方地界的实际主人，豪门宅邸集中于城西。

- **方家**：百年家族，但已**二十年没有出过中阶修者**。家道中落、竞争激烈，族中子弟方鹏举为夺开脉丹不惜谋害结义兄弟姜望。方鹏举死后，方府拒绝其尸身进门，斥其"不仁不义的人，不是方家的种"，仅从门缝扔出一把刀币了事——足见其凉薄与自保姿态。

### 枫林城道院

全城最贵要之地，属庄国道门**玉京山一系**，最重仪轨，修建得富丽堂皇，仅门前一对玉狮子便极富威严与贵气。

- **院长董阿**：五品强者，内府道士，可穿只有中三品强者才允许穿着的腾龙黑袍（右胸绣有栩栩如生的小青龙）。相传他曾在庄国国都**新安城**修行，因方正秉公的性格得罪权贵，才被外放至清河郡枫林城。以枫林城的规模，本只需一位中阶的六品道人坐镇，董阿以五品修为任职，故难免传言其"在庄都得罪了人"。
- 董阿道术以木行造化为主：可令树苗瞬间疯长为决斗高台，化门板为巨手擒敌，种花成大口吞尸。
- **内院选生**：内院院生才是真正被庄国承认的道院弟子，"道院弟子，不可轻辱，更遑论杀伤"。姜望归来后数日，即为内院选生之期。
- 董阿属于**国相杜如海一系**，与城主魏去疾（大将军皇甫端明旧部）派系相异。
- 修为体系：世俗修者境界大致分为九品，九至七品为初阶，六至四品为中阶，三至一品为高阶，同时对应各国官品。

## 关键事件

### 一、姜望归来与方鹏举背叛案

姜望获赐开脉丹（枫林道院仅他一人以功勋获此奖励）后，遭结义兄弟方鹏举嫉恨。方鹏举指使家仆方得财伪造请帖，在望月楼以"两隔阴阳散"毒酒暗算，并勾结西山残匪破门袭杀，夺走开脉丹。姜望大难不死，失踪五十七天后深夜回城，先于倚翠楼后巷擒住方得财逼得供词画押，随即拖着装有方得财的大箱子直接登门道院，当众揭露真相。

### 二、道证死斗

方鹏举杀人灭口不成，反以"错信恶仆"之辞百般脱罪，甚至以道脉初显、层次不同为由拒绝决斗。姜望亮明自己同样已道脉初显，遂请道尊见证，发起**道证死斗**——道门认为道尊高卧九天、洞察宇宙，凡涉道尊之誓无可挽回，道证死斗不死不休。院长董阿亲临主持，以道术生出木台宣布开始。决斗中姜望以腹部迎剑换来割断方鹏举手筋，一个回合即将其击败。方鹏举临死求饶，坦白夺丹因由，最终被姜望一剑贯胸处决。姜望于杀敌之后念头通达，顺利凝出道元。

### 三、方府拒尸

凌河抱着方鹏举的尸体步行至城西方府送还，遭方家拒之门外。门房传话："死都死了，还抬回来做什么？""这种不仁不义的人，不是方家的种！"方家仅扔出刀币让其自行安葬。凌河分文未取，转身离去——"这就是方家的态度""这就是凌河的态度"。

### 四、左道妖人夜袭道院

左道妖人夜入枫林道院行凶，一名庄国修行种子被害。院长董阿勃然大怒，道术覆盖全院，木刺穿杀一名刺客，木手擒获另一名刺客——后者自爆头颅灭口。董阿将声威震动全城，公开宣告"此事必要彻查到底，城主府必须给本院一个交代，无论背后主使者是谁，必诛之"；城主魏去疾遥相回应。此事被姜望解读为：强秦借境伏敌已撕下庄国脸面一层，左道行凶于道院或有试探官方反应之意。董阿借机展示强大、明确态度，以震慑阴影中蠢蠢欲动者——"庄国，并不太平"。
