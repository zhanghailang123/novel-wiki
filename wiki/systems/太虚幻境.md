# 太虚幻境 · 洞天福地

> "于福地演道，于星河论剑，何其雄阔！"
> —— 姜望初入太虚幻境时的心声

---

## 一、词条概述

**太虚幻境**是一个独立于现实之外的玄妙世界，其间星河璀璨、洞天棋布。修者的**灵识**可经由名为**虚钥**的钥匙进入其中——虚钥借助**太阴星力**将宿主的灵识拉入幻境。幻境之内一切拟真：**除不会对宿主现实肉身造成损害外，一切与真实情况无异**。

**洞天福地**是悬于太虚幻境世界包裹中的领地单位（原文以"洞天福地"统称），其中存在明确的排名体系——**七十二福地**。福地主人可定期获得幻境内的通用资源——**"功"**，用于演道推法；但福地之位并非高枕无忧，须定期接受挑战，**失败将降级**。

在今天的姜望看来，这方幻境"潜藏着巨大秘密"，而在此前，他甚至连它的名字都不曾听说过。

---

## 二、进入方式：虚钥

| 项目 | 内容 |
| --- | --- |
| 名称 | 虚钥 |
| 形态 | 一枚小小的、银色的弯月 |
| 原理 | 借助太阴星力，将宿主的灵识拉入太虚幻境 |
| 持有载体 | 化作银月印记烙于持有者右手掌心，平时隐没无形 |
| 触发方式 | 持有者念动时重新显现，勾连太阴星带入灵识 |
| 战斗威能 | 无（本身并无任何威能） |

**虚钥的诞生**：左光烈陨落于还真观外大战后，姜望将其安葬。是夜恰逢满月，皎洁月光照于新坟，点点银光自坟墓中缓缓升起，在月光中汇聚成一枚银色弯月，漂浮于新坟上空。姜望福至心灵，伸手抓住虚钥，眼前一黑，耳边随即响起蕴含天地至理的温和声音——

> "恭迎洞真墟福地之主！"

---

## 三、核心设施

### 1. 演道台
- **功能**：推演功法道术之地。
- **消耗**：推演所需的消耗便是"功"。
- **封印机制**：福地之主的**道元反馈不足**时，演道台将逐层封印。姜望初入时，"演道台十九层封印"逐层落下，直至"演道台二层封印"方止。

### 2. 论剑台
- **功能**：专用于穿梭太虚幻境，与其他修者切磋较技。
- **封印机制**：同样随主人实力低微而封印。姜望初入时，"三品论剑台封印"依次宣告至"八品论剑台封印"。
- 姜望猜测，这些封印皆与其实力低微有关。

---

## 四、资源体系："功"

"功"是太虚幻境中的通用资源，也是演道台推演功法道术的消耗品。

**获取途径：**
1. **战斗产出（主要来源）**
   - 同阶战斗：胜则加功，败则扣功；
   - 越阶挑战：有相应加成。
2. **福地定期产出**
   - 相对应的洞天福地会定期产出"功"。

**七十二福地产功规则：**

| 福地区段 | 产功规则 |
| --- | --- |
| 排名最低的东海山福地 | 每月产功一百 |
| 下三十六福地 | 每升一级，产功加十 |
| 上三十六福地 | 每升一级，产功加一百 |

> **注**：按上述规则推算，排名二十三的洞真墟福地每月产功恰为 1850 点，与姜望入境时所见的"功：1850点"完全吻合。

## 五、洞真墟福地

| 项目 | 内容 |
| --- | --- |
| 福地排名 | 七十二福地中位列**第二十三** |
| 原主人 | 左光烈（据姜望推测："所谓的'洞真墟福地之主'，应当是左光烈而非是他"） |
| 现主人 | 姜望（于还真观外新坟前凭虚钥继任） |
| 月产功 | 1850 点（亦为姜望继任时的初始功值） |
| 内部景象 | 仙气氤氲的空间 |

### 继任始末

姜望安葬左光烈后，坟上银光升腾汇成虚钥。姜望抓住虚钥后，先置身于茫茫黑暗与璀璨星河之间，与一个"身着道袍的自己"合而为一，从而在这神秘世界里获得了某种意义上的实体；紧接着浩瀚星辰骤然翻腾，一整条璀璨星河向他涌来，他遂出现于洞真墟福地那处仙气氤氲的空间中，脑海中同时流过关于太虚幻境的种种讯息，正式成为福地之主。

### 福地挑战与降级

福地之主的位子并非一劳永逸。姜望入境时，目光所及的**日晷虚影**上显现玄黑如墨、字字似千钧的告示：

> 福地主人，将在十五天后，接受福地二十四青玉坛之主的挑战。
> **失败将降级。**

## 六、关联人物

| 人物 | 与太虚幻境的关系 |
| --- | --- |
| **姜望** | 现任洞真墟福地之主。凭左光烈遗留的虚钥入境，初始功 1850 点；右手掌心烙有银月印记，念动即可再入幻境。初入时因道元反馈不足，演道台、论剑台大半被封印。 |
| **左光烈** | 洞真墟福地原主（据姜望推断）。其人陨落后，虚钥自坟中升腾而出，将福地连同 1850 点功一并留予葬他之人。 |
| **福地二十四青玉坛之主** | 将于十五日后挑战姜望福地之位的存在，身份成谜。 |

## 七、设定细节备忘

- 太虚幻境是一个完整的世界，洞真墟福地正处于这个世界的**包裹之中**。
- 幻境中可见一条璀璨星河奔涌，星辰翻腾时整条星河向福地之主涌来。
- 幻境界面文字完全不同于庄国文字，于姜望极为陌生，但他能清楚感知其意义。
- 除福地产功外，"功"尚有"一些其它的方式"获取（原文语焉不详，有待后文揭示）。
- 福地挑战倒计时以"日晷虚影"形式呈现于幻境之中。
- 对庄国底层修者而言，太虚幻境近乎隐秘——姜望在今日之前，甚至连它的名字都没有听说过。
